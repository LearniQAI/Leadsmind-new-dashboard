# Inbox

Quick capture. Drop unsorted notes, meeting scraps, half-formed findings and
"look at this later" items here, then move them to the right folder once they
have a shape:

- a decision → [[02-Architecture-Decisions/README|Architecture Decisions]]
- a security finding → [[03-Security-Audits/README|Security Audits]]
- something consciously not done → [[Deferred-Items-Tracker]]
- milestone status → the relevant `01-Milestones/` note

Keep this folder near-empty. If something has lived here more than a week or
two, it either needs filing or deleting.
