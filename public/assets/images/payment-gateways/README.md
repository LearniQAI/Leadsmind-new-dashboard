# Payment gateway logos

Official logo marks for the providers shown on `/finance/payment-gateways`. Sourced directly
from each provider's own official channels (not third-party icon packs), downloaded once and
committed here rather than hotlinked:

- `stripe.svg` — Stripe's official wordmark (`#635BFF`), from Stripe's public brand SVG.
- `paypal.svg` — PayPal's official two-tone "P" mark.
- `paystack.png` — Paystack's official mark, from Paystack's own verified GitHub organization
  avatar (github.com/PaystackHQ).
- `flutterwave.png` — Flutterwave's official mark, from Flutterwave's own verified GitHub
  organization avatar (github.com/Flutterwave).
- `ozow.png` — Ozow's official icon mark, from ozow.com's own site `apple-touch-icon` asset.

Do not recolor, distort, or crop these — keep each logo's own proportions when placing in the UI.
